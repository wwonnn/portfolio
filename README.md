# 성원희 포트폴리오

메인 사이트: https://wwonnn.github.io/

소개 → 기술 → 이력 → 프로젝트 순서의 밝은 배경 포트폴리오입니다.
프로젝트 카드를 클릭하면 현재 페이지 위에 상세 팝업이 열립니다.
팝업의 × 버튼, Esc 키, 바깥 영역 클릭으로 닫을 수 있습니다.
프로젝트 필터와 목록 위치를 유지하며, 상세 이미지 확대와 다음 프로젝트 탐색을 지원합니다.
