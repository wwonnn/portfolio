프로젝트 소개

매 턴마다 랜덤하게 주어지는 스킬을 활용해 상대방의 알을 모두 맵 밖으로 밀어내는 멀티플레이 전략 알까기 게임입니다.

02 / PROJECT NOTES

기여한 부분 · 스킬 시스템

스킬의 설정 데이터와 실행 로직을 분리하여, 데이터 기반 스킬 시스템을 구현하였습니다.

ScriptableObject에 스킬의 발동 유형, 지속 턴 수 등의 타입을 정의하였습니다. 크기, 무게, 힘 등 스킬별로 필요한 수치는 개별 SO로 분리하여, 실행 코드를 수정하지 않고 Inspector에서 조정할 수 있도록 하여 비개발 직군도 쉽게 스킬을 조정할 수 있게 하였습니다.

SkillFactory는 스킬 객체 생성, SkillContainer는 이름 기반 조회와 실행, SkillBase 추상 클래스와 파생 클래스는 공통 흐름과 개별 효과를 담당하도록 책임을 분리하였습니다.
