# 성원희 포트폴리오 · 다크 전시형 시안

`index.html`을 열어 시작합니다. 홈페이지는 휠 한 번에 페이지가 넘어가며, 소개 → 기술 → 학력·수상 및 활동 → 프로젝트로 진행합니다. 방향키, 화면의 이전·다음 버튼, 상단 메뉴로도 이동할 수 있습니다.

프로젝트 전시는 휠과 드래그로 좌우 이동합니다. 프로젝트 이미지에 마우스를 올리면 카드가 살짝 커지고, 클릭하면 원본의 전체 내용이 담긴 상세 페이지가 열립니다. 목록으로 돌아오면 보던 프로젝트의 위치를 유지합니다. 기술별 필터, 프로젝트 연혁, 연락처, 원본 PDF, 이미지 확대도 사용할 수 있습니다.

모바일에서 페이지 안의 내용이 길면 먼저 해당 내용을 스크롤합니다. 끝에 도달한 다음 제스처에서 다음 페이지로 넘어갑니다. 시스템의 동작 줄이기 설정에서는 페이지 회전과 전시 원근 효과를 줄입니다. 상세 페이지는 긴 본문을 읽기 위한 일반 스크롤을 사용하며 스크롤바는 숨깁니다.

원본의 본문 내용·프로젝트·링크·기간 표기를 유지하고, 웹페이지 연락 이메일은 dnjsgml0508@naver.com으로 변경했습니다. 기존 공개 사이트와 별도로 준비한 미리보기입니다.
